## 4. Recommended order of work

1. **Before any external demo:** configure Mistral on a staging server and run the Copilot questions (AI-02).
2. **Before the first paying pilot:** run tests on managed PostgreSQL, set up email (ALR-02, SEC-10), rehearse backup and restore, and pilot on real phones and scanners.
3. **Pilot phase:** one courier via an aggregator (INT-02), WhatsApp utility alerts, and FBR e-invoicing if the pilot customer is notified (LOC-03).
4. **Growth:** accounting sync, Urdu mobile UI, 2FA, E2E tests, 3PL tiered rates.
